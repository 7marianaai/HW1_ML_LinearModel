# Дерево решений с нуля и классификация пассажиров

Реализация дерева для числовых и категориальных признаков. Сравнение с Random Forest, подбор гиперпараметров, SHAP и LIME. В сохранённом прогоне F1 Random Forest на валидации — 0,957.

## Содержание

- [`AI_HW4_Mariana.ipynb`](AI_HW4_Mariana.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

Часть примеров использует открытые UCI-наборы, часть — students.csv и учебную PostgreSQL БД. Доступ к БД не предоставляется. Параметры подключения читаются из переменных PGHOST, PGPORT, PGDATABASE, PGUSER, PGPASSWORD. При необходимости задайте PGSSLMODE.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.
