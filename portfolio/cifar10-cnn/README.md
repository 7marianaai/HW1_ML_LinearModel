# Классификация CIFAR 10 с CNN

PyTorch CNN с остаточной связью, цикл обучения на GPU, сравнение расписаний learning rate и аугментаций. Сохранённый результат с горизонтальным отражением: test accuracy 0,7294.

## Содержание

- [`Easy_CNN_Mariana.ipynb`](Easy_CNN_Mariana.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

CIFAR-10 скачивается через torchvision. Тестовая выборка использовалась для сравнения нескольких вариантов, поэтому результат является учебным наблюдением, а не оценкой на новом независимом тесте.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.
