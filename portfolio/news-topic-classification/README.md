# Классификация новостей по девяти темам

Сравнение словесных и символьных TF-IDF-признаков, LogisticRegression и LinearSVC. Лучший сохранённый результат на валидации: accuracy 0,9502.

## Содержание

- [`HW3_model_dopolneno.ipynb`](HW3_model_dopolneno.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

Нужен train_data.csv со столбцами title, text, class_id. Метрика относится к валидации, не к внешнему тесту. Формирование submission адаптировано для таблиц с title/text, text или одним текстовым столбцом; новый прогон обучения не выполнялся.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.
