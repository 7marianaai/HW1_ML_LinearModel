| Работа | Что показывает |
|---|---|
| [Регрессия стоимости автомобилей](car-price-regression/) | Предобработка числовых и категориальных признаков, сравнение линейных моделей и регуляризации, создание признаков. |
| [Оптимизаторы с нуля](optimization-from-scratch/) | Реализованы GD, Momentum, Nesterov, AdaGrad, RMSprop и Adam. Исследованы траектории на функции Растригина и поведение двух функций потерь в логистической регрессии. |

| [Классификация CIFAR 10 с CNN](cifar10-cnn/) | PyTorch CNN с остаточной связью, цикл обучения на GPU, сравнение расписаний learning rate и аугментаций. Сохранённый результат с горизонтальным отражением: test accuracy 0,7294. |
| [Определение возраста по фотографии](age-estimation-resnet50/) | Перенос обучения ResNet50 с ImageNet, регрессия возраста, аугментация. 7 591 изображение; MAE на отложенной выборке в сохранённом прогоне — 5,8608 года. |

## Как читать портфолио

Для компьютерного зрения начните с CNN, ResNet50 и выполненной части сегментации. Для понимания алгоритмов — с оптимизаторов, дерева и бустинга. В каждой папке указаны данные, условия запуска и ограничения оценки. Незаполненный шаблон Easy_Linear не опубликован.
