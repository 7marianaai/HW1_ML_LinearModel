# Определение возраста по фотографии

Перенос обучения ResNet50 с ImageNet, регрессия возраста, аугментация. 7 591 изображение; MAE на отложенной выборке в сохранённом прогоне — 5,8608 года.

## Содержание

- [`9e941598-83e7-460b-837c-f14dede8aec1.ipynb`](9e941598-83e7-460b-837c-f14dede8aec1.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

Нужны labels.csv (file_name, real_age) и папка final_files с фотографиями из учебного набора ChaLearn. Код обучения сохранён в Markdown-блоке, как требовал GPU-тренажёр; ноутбук не запускает его автоматически. Отложенная выборка использовалась при обучении как validation.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.
