# Генерация текста с RNN и LSTM

Сравнение рекуррентных языковых моделей, BPE и unigram-токенизации, температуры генерации. Оценка perplexity и сходства текстов в пространстве LSA.

## Содержание

- [`HW3_Mariana.ipynb`](HW3_Mariana.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

Это отчётный ноутбук с сохранёнными результатами. Для полного воспроизведения дополнительно нужны dataset.py, model.py, train.py и исходный текстовый корпус; этих файлов среди вложений нет. Они не восстановлены и не заменены чужими реализациями.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.
