# Генерация текста с RNN и LSTM

Учебный проект по авторегрессионной генерации текста в PyTorch. Сравниваются RNN и LSTM, BPE и unigram-токенизация, размер словаря и температура семплирования. Качество исследуется по perplexity и сходству в пространстве LSA.

## Файлы

- [HW3_Mariana.ipynb](HW3_Mariana.ipynb) — эксперименты, исходные задания и сохранённые результаты
- [dataset.py](dataset.py) — SentencePiece-токенизация, train/validation-разделение, BOS/EOS и padding
- [model.py](model.py) — Embedding, RNN/LSTM, линейный выходной слой и генерация
- [train.py](train.py) — обучение и валидация, CrossEntropyLoss, графики loss и perplexity
- [requirements.txt](requirements.txt) — основные зависимости

## Запуск

1. Скачайте все файлы этой папки в одну директорию.
2. Положите рядом `jokes.txt`: UTF-8 текстовый корпус, один текст на строку. Исходный корпус не предоставлен и не опубликован.
3. Установите зависимости и откройте ноутбук из этой директории:

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook HW3_Mariana.ipynb
```

Сначала выполняются импорты и создание TextDataset. SentencePiece обучает токенизатор и сохраняет файлы `.model` и `.vocab` при первом запуске. Обучение моделей создаёт `.pt` чекпойнты. Для разных вариантов токенизации используйте разные `sp_model_prefix`. Блок оценки ruGPT загружает внешнюю модель через Transformers, поэтому требует сетевого доступа и дополнительной памяти.

## Результаты сохранённого эксперимента

Для BPE с 2000 токенов, BPE с 4000 токенов и unigram с 2000 токенов LSA-показатель составил соответственно 0,6831, 0,6856 и 0,6950. Это результаты исходного учебного эксперимента, а не нового запуска при публикации.

## Ограничения

- Исходный корпус, обученные веса и токенизаторы не включены. Без корпуса нельзя полностью воспроизвести обучение.
- Исторические версии библиотек не зафиксированы. Опубликованные модули прошли проверку синтаксиса; полный цикл обучения при добавлении файлов не повторялся.
- SentencePiece обучается на переданном корпусе до его разделения на train и validation. Это следует учитывать при интерпретации валидационной оценки.
- В исходной функции `inference` при непустом префиксе текст префикса может дублироваться; последний токен префикса повторно подаётся в рекуррентный слой. Реализация опубликована в авторском виде, эти особенности не исправлялись задним числом.
- Perplexity моделей с разными токенизаторами нельзя напрямую использовать как универсальный рейтинг качества генерации.
