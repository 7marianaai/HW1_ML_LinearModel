# Регрессия стоимости автомобилей

Предобработка числовых и категориальных признаков, сравнение линейных моделей и регуляризации, создание признаков.

## Содержание

- [`AI_HW1_Mariana.ipynb`](AI_HW1_Mariana.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

Нужны исходные CSV из задания. В основной папке репозитория уже есть приложение и другая версия проекта. Эта папка содержит дополнительный учебный ноутбук.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.

## Подготовка к публикации

Удалены тяжёлые HTML-отчёты, журналы установки пакетов и технические метаданные. Расчётные результаты и иллюстрации сохранены. Для HW4 реквизиты учебной БД заменены переменными окружения; для HW5 исключены незавершённые задания; в классификации новостей исправлена обработка таблицы внешнего теста и добавлен запуск вне Colab. Исходные формулировки заданий принадлежат авторам курса, решения представлены как учебные работы Марьяны Айрапетян.
