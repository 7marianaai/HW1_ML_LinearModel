# Бустинг с нуля и сегментация изображений

Реализация бинарного градиентного бустинга и сравнение с LightGBM. Сегментация изображений KMeans по цвету и координатам и спектральной кластеризацией.

## Содержание

- [`AI_HW5_Mariana.ipynb`](AI_HW5_Mariana.ipynb) — код, исходные задания и сохранённые результаты
- `requirements.txt` — список основных библиотек без фиксации исторических версий

## Запуск и ограничения

Нужны bank_data.csv, duck.jpg и Owls.jpg. Опубликованы выполненные разделы; незаполненные дополнительные задания исключены. В сравнении бустингов гиперпараметры подбираются по тестовым данным: числа в ноутбуке нельзя считать независимой итоговой оценкой качества.

```bash
python -m pip install -r requirements.txt jupyter
jupyter notebook
```

Исходные датасеты, пароли, веса моделей и дополнительные файлы, не предоставленные для публикации, в репозиторий не включены. Исторические версии библиотек не зафиксированы, поэтому для повторения старых экспериментов может потребоваться адаптация API. Полное обучение не повторялось; опубликованные числа взяты из сохранённых результатов.
